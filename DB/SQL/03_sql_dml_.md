### DATA MANIPULATION LANGUAGE (DML)

> DML CHANGES **DATA** — THE ROWS INSIDE TABLES. IT DOES NOT CREATE OR DROP TABLES.
>
> COMMON COMMANDS: `INSERT`, `UPDATE`, `DELETE`

#### INSERT

> `INSERT` **ADDS NEW ROWS** TO A TABLE.
>
> YOU LIST COLUMNS (OPTIONAL) AND THE VALUES FOR EACH ROW. SKIP A COLUMN → DATABASE USES `NULL` OR `DEFAULT` IF DEFINED.
>
> WHEN WE INSERT DATA TO SPECIFIC (NOT ALL) COLUMNS THE REST OF THEM WILL BE 'NULL'

```sql
-- INSERT ONE ROW (ALL COLUMNS)
-- WHEN YOU DON'T MENTION COLUMNS THEN YOU HAVE TO INSERT IN EVERY COLUMN
INSERT INTO persons
VALUES (1, 'Alice', '1990-05-12', 'alice@mail.com', '555-0100');

-- INSERT WITH NAMED COLUMNS (CLEARER, SAFER)
-- COLUMNS & DATA COUNT MUST BE SAME
INSERT INTO persons (id, person_name, email)
VALUES (2, 'Bob', 'bob@mail.com');

-- INSERT MULTIPLE ROWS AT ONCE
INSERT INTO persons (id, person_name, email)
VALUES
    (3, 'Carol', 'carol@mail.com'),
    (4, 'Dave', 'dave@mail.com');
```

#### INSERT FROM ANOTHER TABLE

> `INSERT INTO ... SELECT` **COPIES ROWS FROM ANOTHER TABLE** (OR QUERY RESULT) INTO YOUR TABLE.
>
> TARGET COLUMNS AND `SELECT` COLUMNS MUST **MATCH IN COUNT AND ORDER** (OR USE NAMED COLUMNS ON BOTH SIDES).
>
> USE `WHERE` ON THE `SELECT` TO COPY ONLY ROWS YOU NEED.

```sql
-- COPY ALL ROWS FROM old_persons INTO persons
INSERT INTO persons
SELECT * FROM old_persons;

-- COPY SPECIFIC COLUMNS ONLY
INSERT INTO persons (id, person_name, email)
SELECT id, person_name, email
FROM old_persons;

-- COPY ROWS THAT MATCH A CONDITION
INSERT INTO persons (id, person_name, email)
SELECT id, person_name, email
FROM old_persons
WHERE person_name IS NOT NULL;
```

#### UPDATE

> `UPDATE` **CHANGES EXISTING ROWS** — SET NEW VALUES FOR ONE OR MORE COLUMNS.
>
> ALWAYS USE `WHERE` TO TARGET SPECIFIC ROWS. **NO `WHERE` = EVERY ROW IS UPDATED.**

```sql
-- CHANGE ONE PERSON'S EMAIL
UPDATE persons
SET email = 'alice.new@mail.com'
WHERE id = 1;

-- UPDATE MULTIPLE COLUMNS
UPDATE persons
SET person_name = 'Robert', phone = '555-0200'
WHERE id = 2;
```

#### DELETE

> `DELETE` **REMOVES ROWS** FROM A TABLE. THE TABLE STRUCTURE STAYS.
>
> ALWAYS USE `WHERE` TO TARGET SPECIFIC ROWS. **NO `WHERE` = ALL ROWS DELETED** (TABLE EMPTY, NOT DROPPED).

```sql
-- REMOVE ONE ROW
DELETE FROM persons
WHERE id = 4;

-- REMOVE ROWS MATCHING A CONDITION
DELETE FROM persons
WHERE email IS NULL;
```
